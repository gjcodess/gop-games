# UI Design

Use this skill for new screens, component composition, visual review, responsive behavior, or interaction polish.

## Visual direction

Build a game-night companion, not a corporate dashboard. Use strong hierarchy, varied composition, game-specific surfaces, purposeful texture/depth, and clear action feedback. Avoid repetitive card grids, arbitrary gradients, glassmorphism, generic sidebars, and default component-library styling.

## Mobile first

Design the narrow layout first. Maintain comfortable touch targets, clear thumb reach, short action paths, sticky context, and useful portrait/landscape behavior. Desktop may add density, not a separate product.

## Interaction

Every meaningful action has a pressed/focus/success/error state. Use motion to explain score movement, progress, turn changes, and randomizer outcomes. Never make essential information depend on animation. Provide reduced-motion and screen-reader alternatives.

## Component discipline

Use shared controls for shared behavior, but keep game-specific visual language in feature modules and theme tokens. Keep CSS scoped with Modules; global CSS is limited to reset, base, tokens, accessibility helpers, and print rules.

## Review checklist

Check hierarchy, action discoverability, loading/error/degraded states, contrast, focus, 44px targets, narrow widths, long-content scrolling, reduced motion, and whether the screen still feels like the selected game.
